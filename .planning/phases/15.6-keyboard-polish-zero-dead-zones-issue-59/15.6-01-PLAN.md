<objective>
Implement the touch forwarding view pattern to eliminate all dead zones and fix edge touch degraded feedback on the UIKit keyboard.

Purpose: The current UIStackView hit-test chain bypasses point(inside:with:) overrides, causing dead zones between keys and degraded feedback on edge touches. A single transparent overlay view (proven pattern from tasty-imitation-keyboard) intercepts ALL touches and routes them to the nearest button by distance, guaranteeing every pixel resolves to a key with consistent touchDown feedback.

Output: KeyboardTouchForwardingView.swift, refactored button touch handlers, zero dead zones.
</objective>

    **1. Create `DictusKeyboard/Views/UIKit/KeyboardTouchForwardingView.swift`:**

    A transparent UIView that intercepts ALL keyboard touches and forwards them to the nearest button via custom methods. This bypasses UIStackView's broken hit-test chain entirely.

    Class `KeyboardTouchForwardingView: UIView`:
    - Property `var allButtons: [UIView] = []` -- flat array populated by KeyboardContainerView after buildKeys()
    - Private property `private var touchToButton: [UITouch: UIView] = [:]` -- tracks which button each active touch is targeting
    - Override `hitTest(_:with:)` -- always return `self` if point is inside bounds (claim all touches)
    - Override `touchesBegan(_:with:)` -- for each touch: find nearest button via `findNearestButton(to:)`, store in `touchToButton`, then dispatch:
      - If button is `LetterKeyButton`: call `button.handleForwardedTouchDown(touch: touch, in: self)`
      - If button is `BaseSpecialKeyButton`: call `button.handleForwardedTouchDown(touch: touch, in: self)`
    - Override `touchesMoved(_:with:)` -- for each touch: look up button from `touchToButton[touch]` (SAME button, never re-route mid-touch), dispatch `handleForwardedTouchMoved(touch:in:)` on the button
    - Override `touchesEnded(_:with:)` -- for each touch: look up button, dispatch `handleForwardedTouchUp()`, remove from dictionary
    - Override `touchesCancelled(_:with:)` -- same as touchesEnded but dispatch `handleForwardedTouchCancelled()`, remove from dictionary
    - Private method `findNearestButton(to point: CGPoint) -> UIView?` -- iterate `allButtons`, convert each button's center to self's coordinate space via `button.superview!.convert(button.center, to: self)`, compute squared Euclidean distance `dx*dx + dy*dy`, return button with smallest distance

    CRITICAL RULES:
    - Once a touch begins on a button, ALL subsequent move/end/cancel for that UITouch go to the SAME button (preserves accent drag, space trackpad, delete repeat)
    - Use custom `handleForwardedTouch*` methods, NOT `button.touchesBegan()` directly (avoids UIKit touch ownership conflicts per Research pitfall #1)
    - Guard `!isHidden && isUserInteractionEnabled && alpha > 0.01` in hitTest

    ```swift
    override func hitTest(_ point: CGPoint, with event: UIEvent?) -> UIView? {

        // ForwardingView is topmost subview -- it intercepts all touches
        return forwardingView.hitTest(convert(point, to: forwardingView), with: event)
    }
    ```
