  </what-built>
  <how-to-verify>
Install the app on simulator (or physical device). Open Notes or any app with a text field. Activate the Dictus keyboard. Test each requirement:

**DZ-01: Zero dead zones**
- Tap precisely between two adjacent letter keys -- both taps should register (one on each key)
- Tap in the gap between rows -- should register on nearest key
- Tap at the very edge of the keyboard (left/right margins) -- should register on edge key
- Try tapping between shift and first letter, between last letter and delete

**DZ-02: touchDown audio + haptic**
- Tap a letter key: sound should play IMMEDIATELY on finger touch, not on finger lift
- Same for space, return, shift, delete

**DZ-03: Key popup preview**
- Press and hold a letter key briefly: popup should appear above the key showing the letter
- Release: popup disappears

**DZ-04: Accent long-press**
- Long-press "e" for ~400ms: accent strip should appear (e, e with accent, e with grave, etc.)
- Slide finger to select an accent
- Release to insert selected accent

**DZ-05: Delete repeat**
- Type "hello world test"
- Hold delete key: first character deletes immediately, then repeats after ~400ms
- Continue holding: after ~10 deletions, switches to word-level deletion (faster, bigger jumps)

**DZ-06: Space trackpad**
- Long-press space bar for ~400ms: grey overlay should appear
- Drag horizontally: cursor should move through text
- Release: trackpad deactivates, overlay disappears

**DZ-07: Shift states**
- Tap shift: labels change from lowercase to uppercase
- Type one character: auto-unshifts back to lowercase
- Double-tap shift quickly: caps lock activates (capslock.fill icon)
- Tap shift again: caps lock deactivates

**DZ-08: Layer switching**
- Tap "123": number/symbol keys appear
- Tap "#+=": second symbol layer appears
- Tap "ABC": back to letters

**DZ-09: Dark mode**
- Toggle appearance in Simulator: Features > Toggle Appearance
- Key backgrounds should update (dark: grey, light: white)

**DZ-10: Text insertion**
- Type "Bonjour le monde" -- verify correct characters appear
- Use space, return, delete -- all work correctly
- Type after autocapitalize triggers (start of field, after ". ")
  </how-to-verify>
